# Documentation Guide

`docs/` contains durable guidance for people changing published crop-reference content or code. Keep these documents accurate to the current implementation.

| Document | Use it for |
| --- | --- |
| `crop-protection-data.md` | Data authoring, evidence states, source boundaries, and validation rules. |
| `crop-protection-images.md` | Image catalog, asset layout, and image-review requirements. |
| `recommendation-flow.md` | Current crop-protection decision and evidence flow. |
| `templates/` | Starting JSON shapes for new records. |

## Development Work

Active product design, roadmap work, and implementation plans live in [`../dev/`](../dev/), not in this folder. Those files may describe planned behavior that is not yet implemented.

When a development decision becomes implemented and stable, update the appropriate document in `docs/` and, when useful, record the decision in `dev/decisions/`.
